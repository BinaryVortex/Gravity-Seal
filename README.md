# Gravity-Seal

Gravity Seal — a small interactive gravity/particle demo built using HTML, CSS and JavaScript.

![Gravity Seal screenshot](./Screenshot%202024-08-23%20093103.png)

## Overview

This project demonstrates a simple browser-based simulation where objects respond to gravity-like forces and user interaction. It's implemented with plain JavaScript (no frameworks) and styled with CSS.

## Features

- Lightweight, client-side demo (HTML/CSS/JS only)
- Interactive: click/drag (if supported) to interact with the simulation
- Smooth particle motion and simple collision/behavior logic

## Live Preview

To view the demo locally:

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Gravity-Seal.git

2. Open `index.html` in your browser (double-click or serve with a local HTTP server):

   - Using Python 3: `python -m http.server 8000` and visit `http://localhost:8000`

## Project structure

- `index.html` — demo entry point
- `style.css` — styles for the demo
- `script.js` — main JavaScript that runs the simulation
- `Screenshot 2024-08-23 093103.png` — example screenshot shown above
